# 검색 성능 측정 결과

## 1. 게시글 1만 건에서 LIKE 단일 요청 기준 측정

2026-11-10 (KST), #83

검색 실험 서버에 테스트 게시글 1만 건을 적재하고, 제목·본문 포함 검색의 첫 페이지를 측정했다. macOS에서 k6 v2.1.0을 실행해 HTTPS로 서버에 요청했다. 서버 배포 이미지 SHA는 이번 실행에서 확인하지 못했다.

| 항목 | 조건 |
|---|---|
| 데이터 | 벤치마크 게시글 10,000건, 작성자 20명, 생성 시드 81 |
| API | `GET /api/posts`, 최신순, 첫 페이지 5건 |
| 실행 | 가상 사용자 1명, 김민재 → 오버래핑 → 아약스 순으로 한 건씩 요청 |
| 표본 | 검색어당 워밍업 10건 제외, 본 측정 200건씩 총 600건 |
| 정상 응답 | HTTP 200과 검색어별 예상 결과 건수 5건·5건·0건 |
| 클라이언트 타임아웃 | 120초 |

| 검색어 | 본 측정 | P50 | P95 | P99 | 최대 | 실패 | 타임아웃 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 김민재 | 200건 | 70.58ms | 73.85ms | 77.53ms | 82.57ms | 0건 | 0건 |
| 오버래핑 | 200건 | 69.60ms | 72.86ms | 81.23ms | 100.64ms | 0건 | 0건 |
| 아약스 | 200건 | 68.51ms | 72.64ms | 101.78ms | 123.47ms | 0건 | 0건 |

세 검색어의 P95는 약 73ms였고, 결과가 없는 아약스의 P99는 101.78ms였다. 검색어당 200건을 측정한 단일 실행이므로, P99 차이의 재현 여부는 이후 측정에서 확인한다. 이 결과는 API 응답시간 기준이며, 화면 표시까지의 시간과 동시 부하 성능은 별도로 측정한다.
